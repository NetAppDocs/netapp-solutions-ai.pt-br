[[4-1-netapp-xcp-core-value]]
== 4.1 NetApp XCP — valor essencial

O XCP é a camada de mobilidade que desacopla a localização dos dados da localização da computação. Uma única opção de configuração (`xcp++_++copy++_++destination`) determina se os dados preparados e os artefatos do modelo serão armazenados no NetApp ONTAP S3 ou em uma camada de alto desempenho do LustreFS, com  `model++_++training`,  `fine++_++tuning` e  `inferencing` lendo e gravando automaticamente no mesmo destino.
